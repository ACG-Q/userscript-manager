# /enable /disable - 启用/禁用脚本

## 语法

```
/enable <script_id>
```

```
/disable <script_id>
```

## 说明

- 切换脚本的启用状态（`enabled` 字段）
- 禁用的脚本不会在生成的安装列表中显示为可用
- 但不会删除源码和生成的文件，可随时重新启用
- 适用于自写脚本和同步脚本

## 示例

### 启用脚本

```
/enable f9076f78-e878-4095-b53c-71d63e7ff556
```

### 禁用脚本

```
/disable f9076f78-e878-4095-b53c-71d63e7ff556
```

## 输出示例

### 启用成功

```
✅ 已启用脚本 f9076f78-e878-4095-b53c-71d63e7ff556
```

### 已经是启用状态

```
ℹ️ 脚本 f9076f78-e878-4095-b53c-71d63e7ff556 已经是启用状态。
```

### 禁用成功

```
⏸️ 已禁用脚本 f9076f78-e878-4095-b53c-71d63e7ff556
```

### 已经是禁用状态

```
ℹ️ 脚本 f9076f78-e878-4095-b53c-71d63e7ff556 已经是禁用状态。
```
