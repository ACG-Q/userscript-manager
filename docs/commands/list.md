# /list - 列出所有脚本

## 语法

```
/list
```

## 说明

显示当前仓库中所有脚本的列表，包括：
- 启用状态（✅ 启用 / ⏸️ 禁用）
- 脚本类型（📝 自写 / 🔄 同步）
- 脚本 ID
- 脚本名称
- 版本号
- 同步脚本会显示上次同步时间

## 示例

### 基础用法

```
/list
```

### 输出示例

```
📋 脚本列表：
  ✅ 📝 f9076f78-e878-4095-b53c-71d63e7ff556 | 测试脚本 v3 (v1.0.2)
  ✅ 📝 c91552a1-8c0a-4170-bd6f-5836cbed7544 | 另一个脚本 (v2.0.0)
  ✅ 📝 5eb89853-6306-4684-8705-777c9b501d8b | 带文档的脚本 v2 (v1.0.1)
  🔄 🔄 a1b2c3d4e5f6 | GreasyFork 脚本 (v1.5.0) (上次同步: 2026-01-15)
```
